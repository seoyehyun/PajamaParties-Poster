# CPU 쪽 KV swap이 CPU–GPU 동시 실행의 GPU 간섭을 줄이는가 (Orange Pi 6 Plus, 2026-11-19)

corun-kvswap-plan.md의 본 실행 결과다. 스크립트는 [corun_kvswap.py](../../code/scripts/joint/corun_kvswap.py). 원본은 `runs/corunkv_20261111_113750/`(git 제외, 보드 시계 기준 11/11 날짜)이고, 아래 두 CSV가 그 요약이다.

| 파일 | 내용 |
|---|---|
| `corun_kvswap_20261119_summary.csv` | (KV 모드, A720, GPU)별 두 회차 평균 |
| `corun_kvswap_20261119_windows.csv` | GPU 구간 16개 각각(CPU, GPU 속도, 슬로다운, 추정 GPU 대역폭, 최고 온도) |

## 조건

- CPU 작업 하나(Qwen3-1.7B Q4_K_M, 약 7,000토큰 프롬프트, ctx 12288, A720 8스레드)가 decode하는 동안 GPU 작업(`llama-bench` Vulkan, `-ngl 99`, tg64 × 4회, 호스트 스레드 1개를 A520에)을 구간으로 끼워 넣었다. CPU의 KV는 **RAM(전체 어텐션)** 또는 **디스크 swap**(KV swap, M=50, G=8, W=256, NVMe direct I/O)이다.
- A720은 1500 MHz 고정 또는 기본 거버너, GPU는 600 또는 1000 MHz 고정. 8개 조합 × 2회 = CPU 프로세스 8개와 GPU 단독 4개. 회차마다 순서를 섞었다. 두 회차의 값이 거의 같다(예: ram, 기본, GPU 1000의 GPU 구간 85.8, 86.9 ms/tok).
- **GPU 슬로다운** = 동시 실행 중 GPU 작업 ms/token ÷ GPU 단독 ms/token − 1(단독: 600 MHz 59.7, 1000 MHz 37.6 ms/tok).
- perf 대역폭은 이 실행에서 기록하지 않았다(`SUDO_PASS` 없이 `--no-pmu`). **후속 실험에서 컨텍스트 3K, 7K, 11K 모두 perf로 A720 읽기 대역폭을 기록했고, KV swap에서 약 절반으로 줄었다**([corun-kvswap-ctx-20261119.md](corun-kvswap-ctx-20261119.md)).
- 보드는 중간에 재부팅 없이 16개 구간을 모두 마쳤고, 읽기 횟수 확인(P1: 1716 vs 1714)도 통과했다.

## 결과

| A720 | GPU | KV | GPU 작업 ms/tok (단독 대비) | **GPU 슬로다운** | CPU 단독 ms/tok | CPU 슬로다운 | 최고 온도 |
|---|---|---|---|---|---|---|---|
| 기본 | 1000 | ram | 86.4 | **+130%** | 77.3 | +4.0% | 71 °C |
| 기본 | 1000 | **swap** | 50.8 | **+35%** | 68.3 | +1.7% | 65 |
| 기본 | 600 | ram | 119.4 | **+100%** | 77.2 | +2.5% | 71 |
| 기본 | 600 | **swap** | 75.2 | **+26%** | 68.3 | +0.5% | 65 |
| 1500 | 1000 | ram | 61.5 | **+63%** | 76.6 | +6.1% | 60 |
| 1500 | 1000 | **swap** | 45.1 | **+20%** | 78.5 | +5.3% | 56 |
| 1500 | 600 | ram | 88.2 | **+48%** | 82.2 | +3.8% | 60 |
| 1500 | 600 | **swap** | 65.6 | **+10%** | 78.5 | +3.7% | 56 |

KV swap으로 바꾸면 **GPU 슬로다운이 38~95%p 줄었다.** 네 조합 모두 같은 방향이고, 두 회차에서 모두 재현됐다(윈도우 CSV에서 swap의 GPU 슬로다운은 회차 간 차이가 5%p 이내).

## 해석

- **CPU 쪽 KV 오프로딩이 GPU 간섭을 크게 줄인다.** A720 기본, GPU 1000에서 GPU 작업이 86.4 → 50.8 ms/token으로 빨라진다(0.59배). 그 조합에서 최고 온도도 71 → 65 °C로 낮다.
- **A720 1500 MHz와 KV swap은 서로 더해진다.** GPU 1000 기준 기본+ram 86.4 → 1500+ram 61.5 → 기본+swap 50.8 → **1500+swap 45.1 ms/token**(기본+ram 대비 0.52배, 단독 37.6의 1.20배). 최고 온도는 56 °C다. 앞선 열 A/B에서 본 "두 효과가 거의 곱으로 합쳐진다"가 간섭 쪽에서도 맞다.
- **CPU 작업은 거의 손해가 없다.** swap에서 A720 기본일 때 CPU ms/token이 68.3으로 ram(77.3)보다 오히려 빠르다(0.88배, 앞선 열 A/B의 TPOT 0.90과 일치). 1500에서는 ram과 swap이 78.5 ± 4로 같다. CPU 슬로다운(동시 실행 때문에 CPU가 더 느려지는 정도)은 모든 조합에서 0~6%다.
- **GPU 600 MHz는 여기서도 이득이 없다.** GPU 1000이 GPU 600보다 어느 조합에서든 ms/token이 낮다. 동시 실행 열 A/B의 결론(GPU는 최대)과 같다.
- **추정 원인(검증 안 함):** KV swap은 decode마다 선택한 KV 그룹만 읽어서 CPU의 DRAM 읽기가 줄고, 그만큼 GPU가 쓸 수 있는 대역폭이 늘어난다는 해석이다. 구간별 GPU 추정 대역폭(`모델 크기 × tokens/s`)이 swap에서 더 높다(예: A720 기본, GPU 1000에서 ram 14.8, swap 25.1 GB/s). 그러나 A720의 실제 읽기 대역폭을 재지 못했다. KV swap의 I/O 스레드가 만드는 경합이 있는지도 보지 못했다.

## 사전 계산 테이블에의 의미

[precomputed-table.md](precomputed-table.md)의 동시 실행 행에 KV 축이 생긴다.

| 지배 자원 상태 | 열 최저, 속도를 지키는 조합 | 근거 |
|---|---|---|
| CPU와 GPU 동시, CPU 작업이 긴 컨텍스트 | **CPU는 KV swap, A720 1500, GPU 1000** | GPU 작업 86.4 → 45.1 ms/tok(0.52배), 최고 온도 71 → 56 °C, CPU 작업 속도 유지 |

앞선 동시 실행 열 A/B(KV 위치 변수 없음, 짧은 컨텍스트)에서는 CPU 작업이 1.12배로 제약을 넘었지만, 여기서는 KV swap이 CPU 속도를 지켜서 그 충돌이 줄어든다. 다만 두 실험은 조건이 달라(컨텍스트 7K와 약 1K, 구간 방식과 요청 반복) 직접 비교하지 않는다.

## 한계

- **열 면적이 아니라 구간별 최고 온도만 비교한다.** 이 설계는 구간이 섞여 있어 에너지 대리 지표(열 면적)를 내지 않는다. 온도 차(71 vs 56 °C)는 A720 고정 효과가 섞여 있다.
- 모델 하나, 컨텍스트 하나(7K), 반복 2회다. GPU 작업은 짧은 컨텍스트(tg64)다.
- A720 대역폭을 재지 않아서 원인은 추정이다.
- GPU 작업 구간은 25~65초이고, GPU 1000과 600의 구간이 서로 다른 CPU decode 위치(컨텍스트 길이)에서 잰다. 같은 CPU 프로세스 안의 solo 구간 사이 차이(중앙값 12.8%, 최대 19.4%)가 CPU 슬로다운의 노이즈 하한이라서 **CPU 슬로다운 0~6%는 노이즈 안**이다. GPU 슬로다운 차이(수십 %p)는 이보다 훨씬 크다.
- A720 `def`는 기본 거버너라 실제 주파수가 실행 중에 바뀐다. 1500 MHz는 요청값이다.
- KV swap은 CPU 프로세스에만 있다. 한 프로세스에서 GPU와 같이 쓰는 것은 여전히 세그폴트가 난다.

## 다음

1. perf로 A720 읽기 대역폭을 같이 기록한다(`SUDO_PASS` 필요). "CPU DRAM 수요 감소 → GPU 간섭 감소" 가설을 직접 확인한다.
2. A720 800 MHz, GPU 350 MHz와 다른 컨텍스트 길이(예: 3K, 12K)에서도 같은 방향인지 확인한다.
3. 같은 설계로 구간 대신 전체 요청의 열 면적을 재서 에너지 대리 지표로 비교한다.
